# Queue Completeness checkpoint (local candidate only)

Implemented the frozen six-section Claude Queue package. Open, Deferred, Dismissed, Resolved and History use one pure request-time projection and matching list counts. Defer and Dismiss keep the exact existing claim-content digest; the engine, digest and real-decision merge semantics are unchanged. Real decision/previous-cycle behavior remains intact. The latest timestamp/ID row alone applies; a returning digest reapplies its disposition, withdrawal appends history, and next-review deferral ends only after a scoped Final strictly after the disposition.

Persistence is append-only `finding_dispositions`: SQL0032 exposes scoped guarded command/read RPCs, binds the fresh actor, serializes the derived comparison, checks digest/latest expectations, and returns typed refusals. Retries return their original receipt without another activity event. UPDATE/DELETE are denied by grants and by an operator-resistant trigger. Local writes use the existing paired journal under the owner lock; local store history guards refuse rewriting/deleting dispositions. Invalid/replay results do not commit another local transaction. Reopened activity is an idempotent evaluator observation, without attributing an automatic transition to a human decision.

Decisions keeps Make a decision primary, adds secondary defer/dismiss sheets, Return to Open, reason retention, conflict actor/time, exact-claim/source links and derived reopened history. Viewer controls are hidden and both server guards deny writes. No new role, navigation destination or decision-authority restriction was added. Existing Member business writers retain their authority.

Home/portfolio, operational Analysis and Weekly Open counts use the same Queue projection. Future Weekly inputs freeze disposition rows/finalization timestamps and show Deferred/Dismissed records inside their cutoff window. Existing Final bytes are never rewritten. A date boundary changes the current Draft digest so a stale section can refresh without getting stuck behind hidden Refresh controls. Optional empty Queue keys are omitted to preserve historical empty-source digest inputs. Root0033 extends the SQL current-finding helper for Minimum Context; Queue does not invent another context/digest scheme.
