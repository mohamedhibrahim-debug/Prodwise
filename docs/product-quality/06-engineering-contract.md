# Engineering boundaries for design freeze

No implementation in this artifact. Root owns integration, schema, authenticated organization switching, request-scoped read deduplication and release gates.

- Stage is the existing `initiative.stage`. Add one guarded and audited optimistic-concurrency mutation, preserving current claim/evidence semantics. Do not create a delivery STAGE kind or infer stage from Target/Actual Live. General decisions use existing confirmed DECISION Knowledge; conflicting-value outcomes continue through the established workbench.
- Delivery fields use existing fact revisions, source/basis and before/after events. Weekly structured updates explicitly confirm that the initiative changes. Commentary-only saves never mutate facts. Refresh after canonical writes must mark affected sections for human recheck; Final remains immutable.
- Project metrics require an additive scoped table, not per-page fixtures: definition/name/unit/formula, source/evidence, reporting period, numeric observations, optional target, approval/owner label and timestamp, freshness, explicit synthetic origin. Missing values remain null. MVP exposes honest measurement detail; no simulated integration or unsupported editing controls. Operator seeds only registered Demo. Real organizations with no measurements remain unconfigured.
- Organization switch is an explicit server action over the current verified identity/session, with active target membership or persisted platform authority, target status/policy checks, pinned guest denial and audit. It must not infer authority from email. Viewing an admin target does not change product context. A successful switch resets the client context and lands on Home; old forms must not change the new organization accidentally.
- Read optimization uses React cache scoped to a single request/render only. Mutation paths use fresh access and existing DB authority/revision checks. No process-wide session, membership, source truth or tenant cache. Retain no-store responses and never merge scope through a client filter.
- Existing Demo W38 Final is immutable. Enrichment appends synthetic initiatives/source/facts and refreshes the Draft with meaningful additions/deltas, preserving prior history. Any withdrawal has a recorded event. The operator path validates exact registered organization/workspace/user and never targets AMAN. Reset/reseed archives prior generations and explicitly repoints guest configuration only after validation.
- One shared portfolio projection should derive attention, upcoming, target history and recent meaningful changes for Home/register/Analysis. Existing deterministic mismatch rules do not establish readiness or business impact. Coverage and attention are separate.

All migrations must be additive and replayed locally in order with RLS, ACL, foreign-scope, Viewer, stale-write and audit tests before any production application. No production write during research/design or incomplete local quality gates.
