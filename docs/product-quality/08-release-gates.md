# Integrated quality and release gates

The current live baseline remains `79875f8` until the complete next candidate passes these gates. Research artifacts are committed separately; no research commit is a release approval.

1. **Design:** official-source research consumed by IA/UX specialists; Claude product lead's concrete recommendation captured; implementation ownership/route/data contracts frozen. Rendered screenshots must return to Claude after implementation.
2. **Truth:** shared projection tests cover no sources, unverified claims, confirmed differing values, resolved decisions, withdrawn/unknown facts, partial versus full Actual Live, scope-specific target revisions, missing measurements and immutable prior Finals. Demo story tests prove every surface uses the same eight-initiative record.
3. **Weekly:** separate commentary save/review confirmation; canonical field update with explicit scope and source; stale/foreign/Viewer denial; preserved target history; changed section requires recheck; human Final; immutable Final; next-week comparison; real Claude generation and honest template fallback. No invented unsupported facts.
4. **Access:** both persisted Platform Owners; normal organization roles; global versus scoped controls; protected owners; organization policy/explicit override audit; safe organization switching; pinned Demo switch/API/deep-link/search denial; existing signup/anonymous settings unchanged. New scope-independent forms must reject stale organization intent.
5. **Database:** ordered additive migration replay and ACL/RLS/foreign-key/optimistic-concurrency/audit tests. Backups/preservation hashes distinguish pre-existing real records and immutable Finals from explicitly authorized synthetic enrichment.
6. **Browser:** desktop/mobile screenshots for Login, entry, Home, register, four initiative surfaces, Roadmap, two Analysis routes, platform/org/users/account, orientation/Help and Weekly. Responsive 390/768/1024/1440+, no document overflow, errors, failed reads or exposed secrets. Keyboard/focus/labels/landmarks/semantics/reduced motion; axe plus manual probes with limits reported honestly.
7. **Performance:** same five routes, three warmed samples, destination content visible; endpoint counts and shell/document behavior measured before/after. Loading feedback is reported separately from completed navigation. No authorization or cross-tenant truth cache.
8. **Independent review:** fresh high-capability reviewer, separate from the design session, checks CEO/Lead/PM/Platform Owner/Demo journeys against rendered candidate. Fix blocker/major findings and recapture affected evidence.
9. **Release:** clean tracked candidate, exact tested SHA, non-destructive approved migrations/enrichment, existing production deployment only. Verify Vercel completion/Production/current-alias SHA, complete production smoke, grounded Claude, Demo isolation and bounded runtime/secret checks. Do not submit the instructor form.

Final evidence must not call enabled controls a successful mutation, source inspection a browser test, URL change completed rendering, fixture attribution a human action, or an automated accessibility scan a screen-reader test.
